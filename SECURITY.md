# Security

Vigiver explores mechanisms for investigating, protecting, and recovering blockchain infrastructure.

Because the project itself operates within a security-sensitive domain, independent research and responsible disclosure are encouraged.

## Current scope

The project is under active development and initially targets test networks.

Experimental contracts, signing mechanisms, and recovery workflows should not be used to protect production assets.

A successful test or automated security assessment does not establish that a system is free of vulnerabilities.

## Reporting vulnerabilities

If you discover a vulnerability that could affect users, assets, authorization mechanisms, or contract integrity, please avoid publishing exploitable details before they can be reviewed.

Use GitHub's private vulnerability reporting feature if it is enabled for this repository. Otherwise, request a private communication channel without exposing the vulnerability publicly.

Useful information includes the affected component, reproduction steps, expected behavior, observed behavior, and potential impact.

Never include real private keys or personal information.

## Research responsibly

Use local environments, forks, test networks, and systems for which you have authorization.

The project welcomes reproducible evidence and constructive criticism. Its security claims should remain open to investigation and independent verification.

Security findings will inform subsequent tests, fixes, and contract releases.
